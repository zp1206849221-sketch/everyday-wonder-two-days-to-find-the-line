# Everyday Wonder, Two Days to Find the Line

An entry for the make.fun contest "Everyday Wonder, Two Days to Find the Line":
a single sentence (at most 200 characters) about a small moment of wonder in
everyday life. This entry finds it on a braking train, where a carriage of
strangers' coffees all lean forward at the same instant — for one stop, the
passengers become islands sharing one small ocean and one brief tide.

## Run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (creating the directory if
needed), ready for the contest gate and judge.
